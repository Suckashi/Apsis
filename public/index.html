CONNECT YOUR ENGINES

連線設定

API key 只在 Node.js 伺服器使用，不會儲存在瀏覽器。

01

啟用 Pi

將專案的 .env.example 複製為 .env，填入你的模型服務金鑰。 

PI_PROVIDER=openai
PI_MODEL=gpt-4.1-mini
OPENAI_API_KEY=你的金鑰

也支援 Anthropic：設定 PI_PROVIDER=anthropic、PI_MODEL=claude-sonnet-4-6 與 ANTHROPIC_API_KEY。

02

連接 Hermes（選用）

連接既有的 Hermes API server，讓 Pi 能委派任務；本工作台不需要 Python。 

HERMES_URL=http://127.0.0.1:8642
HERMES_API_KEY=你的 gateway 金鑰
HERMES_MODEL=hermes-agent

Hermes 本體需另行運行。遠端工具使用該主機的權限與工作目錄，請確認是你信任的 gateway。

修改後重新啟動 npm run dev

連線狀態表示環境變數已設定；實際可用性會在第一次執行時確認。沒有金鑰也可以使用示範模式。
