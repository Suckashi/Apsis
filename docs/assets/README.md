# Documentation screenshots

`conversation.png` is copied from `artifacts/bot-verification/desktop-completed.png`, generated by:

```sh
npm run test:bots:browser
```

It captures the actual Apsis UI using an isolated store, synthetic local source and deterministic runner. It contains no real user's conversation, model credentials or personal browser profile. The source screenshot is copied unchanged and visually reviewed before inclusion. Regenerate it when the documented conversation UI changes; passing a browser fixture is not a real-model benchmark.
