## 2. 已確認的產品方向

產品定位的工作描述：**有固定 Bot 團隊的聊天式研發工作平台。**

第一批使用者是產品擁有者本人。主要工作是：

1. 在已有 Repo 的成熟專案上，平行開發多項需求。
2. 固定時間執行 CI、修復 CVE／issue。
3. 從交辦一路執行到建立 PR，讓使用者 Review，並繼續處理 CI 和 Review 後續。

使用者平常已使用 Kimi Code Web 開發。他想自建的價值包含 Grok Bot 式的聊天工作平台，以及有固定身分、可長期合作的多位 Bot。不能擅自把 Bot 降成只有模型／工具配置的選單。

使用者的核心比喻（原話）：

> 感覺就像是真實世界中老闆派任務下去給自己的員工，只是我們會明確的知道 他現在做到哪裡 正在做什麼 他做過什麼

因此，需要讓使用者清楚掌握工作階段、正在進行的實際操作、已完成的修改與驗證、阻礙、以及待使用者處理的事項。進度可以根據實際工具事件、檔案變更、檢查結果與簡短說明呈現。
