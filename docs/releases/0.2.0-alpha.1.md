# Apsis v0.2.0-alpha.1

First public source Alpha of Apsis, a local-first Bot workspace for conversation, observable execution and saved results. Licensed under Apache License 2.0; vendored Kimi Bash retains its MIT license.

## Included

- Deep Agents Bots with continuing conversations, memory, steering receipts, approvals, schedules, files and downloadable artifacts.
- Native internal `task` subagents and persistent cross-Bot delegation, with expandable public execution records.
- English and Traditional Chinese onboarding, current documentation index, security reporting, contribution forms, roadmap and acceptance plan.
- Version and backup/restore policy, isolated restore integration test, documentation checks and gated source-release automation.

## Install

Requires Node.js 22.19+, npm and Git. Windows/Ubuntu with Node.js 22.19 are the CI baseline. Git for Windows provides Bash for Shell tools; Linux uses system Bash.

```sh
git clone --branch v0.2.0-alpha.1 https://github.com/Suckashi/Apsis.git
cd Apsis
npm ci
npx playwright install chromium
npm start
```

Linux may need `npx playwright install --with-deps chromium`. Open http://localhost:3100, add/test a model connection, select a Bot and send a task. Source ZIP/tar downloads can be extracted and installed with the same npm commands. No npm package or desktop installer is included.

Guides: https://github.com/Suckashi/Apsis/blob/v0.2.0-alpha.1/docs/getting-started.md and https://github.com/Suckashi/Apsis/blob/v0.2.0-alpha.1/docs/getting-started.zh-TW.md.

## Data compatibility

Schema 4 only. Existing schema 4 stores are intended to remain usable by this release; this preparation does not change the runtime/storage format. Checkpoint version 1 is tagged `deepagents@1.14.0`. Older `.apsis/` data is left untouched and is not imported. Stop Apsis and back up the entire data directory before changing versions; external workspaces and environment secrets require separate backups. Do not point older code at newer data to roll back.

Backup procedure: https://github.com/Suckashi/Apsis/blob/v0.2.0-alpha.1/docs/releases.md#backup-and-restore.

## Validation and limits

Publication is gated by documentation/metadata checks, TypeScript, the full test suite and chat/Bot/settings browser fixtures on Windows and Ubuntu. The restore integration test checks a stopped store and persisted records/files. These tests use deterministic runners and do not certify external model credentials or all model behavior.

This is a single-owner Alpha. Shell runs on the host; approvals are not an OS sandbox. APIs and formats may change. macOS CI, long external-model tasks, week-long independent-user trials, complete translation/screen-reader coverage and complex-document print fidelity remain open. See https://github.com/Suckashi/Apsis/blob/v0.2.0-alpha.1/docs/alpha-acceptance.md.

Report ordinary bugs at https://github.com/Suckashi/Apsis/issues/new/choose and vulnerabilities privately at https://github.com/Suckashi/Apsis/security/advisories/new.
